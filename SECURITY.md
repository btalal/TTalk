# Signaler une vulnérabilité

Les limites et le périmètre de sécurité sont décrits dans
[docs/SECURITY.md](docs/SECURITY.md). Les travaux non encore qualifiés sont suivis
dans [docs/NEXT_SECURITY.md](docs/NEXT_SECURITY.md).

Pour une vulnérabilité, utiliser **Security > Report a vulnerability** sur GitHub
si le signalement privé est activé. Sinon, ouvrir une issue demandant uniquement
un canal privé, sans détails permettant d’exploiter le problème. Ne pas publier
de clés, PIN, sauvegardes, messages, codes d’appairage, certificats ou données de contacts.

Indiquer en privé la version/commit, le système, la reproduction minimale et les
conséquences observées avec des données fictives. Aucun délai de correction ni
récompense n’est promis.

Les versions 0.5.1 sont publiées pour le périmètre de leurs essais. La branche 0.6
reste en développement et ne remplace pas ces versions finales avant validation.
