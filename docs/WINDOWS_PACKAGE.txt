TTalk 0.6.1 pour Windows — version finale (Windows 10 et 11, 64 bits)

Avant de lancer cette version, fermez toute version précédente de TTalk.
N'utilisez jamais deux versions en même temps avec le même profil.


INSTALLATION

1. Extrayez l'intégralité du fichier ZIP, puis double-cliquez sur TTalk.exe.
   Contenu du dossier :
     TTalk.exe       lanceur de l'application (avec son icône) ;
     LISEZ-MOI.txt   ce document ;
     app\            fichiers techniques (application, bibliothèques DLL, données).
   Laissez le dossier « app » à côté de TTalk.exe : ne déplacez jamais le
   lanceur seul. Vous pouvez en revanche créer un raccourci sur le Bureau.

2. Créez votre code PIN (de 4 à 12 chiffres), ou saisissez-le s'il existe déjà.

3. Dans le menu « ••• », ouvrez « Configurer le serveur » et saisissez
   l'adresse HTTPS du relais. Tous les appareils doivent utiliser la même
   adresse. Aucune recompilation n'est nécessaire.

4. Choisissez « Mon nom », échangez un code d'appairage avec votre contact,
   puis comparez vos numéros de sécurité.


FONCTIONNEMENT

Votre PC n'a pas besoin de rester allumé : le relais est hébergé en permanence.
Si vous n'avez pas encore d'hébergement, consultez le guide :
https://github.com/btalal/TTalk/blob/HEAD/server/README.md
Node.js n'est utile sur le PC que pour tester avec un relais local.

Les contacts et les clés sont conservés après un redémarrage. Les messages
envoyés sans connexion restent dans le coffre jusqu'au retour du réseau ;
une petite horloge signale un envoi en attente. Le serveur conserve les
messages chiffrés en attente pendant 7 jours au maximum.


NOUVEAUTÉS DE LA VERSION 0.6.1

- Nouvelle interface, identique sur Windows, Mac, Android et iPhone :
  menu Discussions, Contacts et Réglages en bas de la fenêtre.
- Logo, version et état « Connecté » visibles en haut de la fenêtre.
- Avatars illustrés : 20 pour les contacts et 20 pour les groupes, à choisir
  dans « Nom et icône ». Pastille verte sur les contacts vérifiés.
- Nouvelles bulles de messages, filtres sur une ligne, police Inter.

Rappel des nouveautés de la 0.6 : recherche, filtres, conversations
épinglées et archivées, invitations par QR code ou lien, réponses citées,
réactions chiffrées, verrouillage automatique, sauvegarde chiffrée locale.


MISE À JOUR DEPUIS UNE VERSION PRÉCÉDENTE

Vos données Windows et votre PIN sont conservés ; les contacts sont convertis
automatiquement. Les groupes créés avec la version 0.3.6 restent consultables
mais doivent être recréés. Les réactions et les changements de membres d'un
groupe nécessitent que tous les participants utilisent la version 0.6 ou plus.


SÉCURITÉ

Les fichiers reçus sont enregistrés déchiffrés dans Documents\ttalk_files.
Protégez donc votre session Windows et n'effacez pas les clés de l'application.
Ce paquet n'est pas signé (Authenticode) : vérifiez son empreinte SHA-256,
publiée à côté du fichier ZIP.

Les notifications sur mobile ne sont pas encore disponibles : la réception
reprend à l'ouverture de l'application.
