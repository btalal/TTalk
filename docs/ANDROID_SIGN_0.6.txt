TTalk Android 0.6.1 — signature de production

L’APK ttalk-android.apk publié sur GitHub est déjà signé. Le build 30 apporte
les 85 choix illustrés. Installer par-dessus la 0.6.0/0.6.1, sans désinstaller.

Pour signer un nouveau build local, utiliser la clé de production de la 0.6,
conservée hors du dépôt et de GitHub Actions. Ne pas utiliser une clé Test.

apksigner sign --ks CHEMIN_DU_KEYSTORE --ks-key-alias VOTRE_ALIAS --out ttalk-android.apk app-release.apk
apksigner verify --verbose --print-certs ttalk-android.apk

Le mot de passe est demandé localement par apksigner. Ne pas le communiquer.
L’empreinte SHA256 du certificat attendue pour la 0.6.0/0.6.1 est :
a843a0168c52c76a040f34bf8234603a93e24c6d75ea28e8438f62c376a66e5c

Les versions 0.5.1 utilisaient un autre certificat ; suivre les notes de version
pour une migration depuis cette ancienne version.
